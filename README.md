# MaBricole Mobile Assets

Public visual assets used by the MaBricole Flutter application and FluxBuilder.

Raw file base URL:

```text
https://raw.githubusercontent.com/mabricole/mabricole-mobile-assets/main/
```

## Structure

- `banners/fr` and `banners/ar`: localized home banners
- `illustrations/fr` and `illustrations/ar`: localized home illustrations
- `icons/categories`: category and subcategory icons
- `icons/social`: social network logos
- `languages`: language selector visuals
- `logos`: MaBricole wordmarks
- `onboarding`: first-launch screens
- `notifications`: notification permission visuals
- `loading` and `splash`: animated loading and launch visuals
- `assistant`: MaBricole assistant mark
- `payments`: payment method logos

This repository contains public media only. API keys, signing files, customer data,
and application source code must never be added here.
